How students apply

All routes start with the course application in the Applicant Portal, submitted by the course funding deadline with “Yes – I wish to apply for funding” ticked (University guidance). College conditions are independent of the route: each award shows one label combining both, e.g. “Automatic — if accepted by Christ’s College”. Click a box to filter the list.
